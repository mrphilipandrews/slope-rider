# Slope Rider

A snowboard game for Year 8 maths: plot linear graphs, find gradients and intercepts, and write y = mx + c. Six runs from Bunny Hill to Double Black, each with an Explore stage and a Challenge.

Play: https://mrphilipandrews.github.io/slope-rider/

One self-contained HTML file. Progress is saved in the browser only. Teacher links: add `#teacher` to unlock every run, `#teacher-run4` to open a run, or `#teacher-run4-challenge` to jump to its Challenge.
